Web NFC 使用说明

1. 用 NFC Tools 等 App 给每张贴纸写入文本 MAP:01（数字=点位编号）。
2. 在 Android 版 Chrome 打开本页面，保持页面在前台。
3. 点击下方「启动 NFC 监听」，将手机贴近贴纸即可点亮对应点位。
4. 苹果 iPhone 不支持 Web NFC，可用 ESP32 方案替代。

扫码打卡 · 点位二维码

为每个点位生成一张码，扫哪张就只点亮那个点位。现场把每张码贴在对应点位，游客扫码即完成该点位打卡；Android 也可改用 NFC 贴纸。需把页面部署到 http(s) 地址后二维码才有效。

打卡定位校验（防作弊）

现场打卡前会用手机 GPS 校验你是否在该点位附近（默认 100 米内），超距或定位被拒都不会点亮，避免远程打卡。模拟点击与网络读卡器不受此限制。
